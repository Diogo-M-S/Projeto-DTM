# Projeto DTM

# ⚡ Dimensionamento Elétrico - Calculadora de Fios e Disjuntores

> Uma ferramenta desenvolvida para auxiliar nos cálculos de dimensionamento elétrico residencial/predial, automatizando a escolha ideal da bitola dos condutores (fios/cabos) e da corrente nominal dos disjuntores.

---

## 📋 Sobre o Projeto

O dimensionamento correto de uma instalação elétrica é fundamental para garantir a segurança contra sobrecargas e curtos-circuitos, além de evitar perdas de energia, gastos desnecessários com materiais superdimensionados e contas elétricas elevadas.

Este projeto tem como objetivo simplificar esse processo, recebendo os dados básicos do circuito (potência, tensão, tipo de instalação, etc.) e retornando recomendações técnicas precisas para a escolha dos componentes.

### ✨ Funcionalidades

- [x] **Cálculo de Corrente de Projeto:** Determina a corrente elétrica nominal do circuito com base na potência (W ou VA), tensão (127V/220V/380V).
- [x] **Dimensionamento de Disjuntores:** Indica o disjuntor termomagnético ideal para proteger o condutor escolhido sem desarmes indevidos.
- [ ] **Dimensionamento de Condutores (Fios/Cabos):** Sugere a seção nominal (mm²) adequada levando em conta a capacidade de condução de corrente e fatores de correção (temperatura e agrupamento).
- [ ] **Cálculo de Queda de Tensão:** Verifica se a bitola escolhida respeita os limites de queda de tensão estabelecidos por norma para a distância informada.
